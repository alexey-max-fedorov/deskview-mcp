# Privacy Policy

**deskview-mcp** is a local MCP server. It runs entirely on your Mac and
does not transmit any data to external servers, third parties, or the
internet.

## What this software does

- Captures frames from your Mac's Desk View camera on demand
- Returns those frames directly to the Claude client that invoked the tool
- Processes all image data in memory on your local machine

## What this software does not do

- Send images, metadata, or any other data to any external service
- Store captured frames to disk
- Log or record usage
- Collect personal information of any kind

## Camera access

macOS will prompt you for camera permission the first time the tool runs.
This permission is used solely to access the Desk View (Continuity Camera)
feed. You can revoke it at any time in System Settings → Privacy & Security
→ Camera.
